# zorinto/homebrew-chinwag

Homebrew tap for chinwag: read, reply to and manage WhatsApp Desktop chats from the Mac terminal, through the official WhatsApp app.

```sh
brew install zorinto/chinwag/chinwag
chinwag doctor
```

The formula installs the same prebuilt Apple silicon binary as the npm package [@zorinto/chinwag](https://www.npmjs.com/package/@zorinto/chinwag), whose README is the full guide. macOS on Apple silicon only.
