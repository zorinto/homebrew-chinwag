# zorinto/homebrew-chinwag

Homebrew tap for [chinwag](https://github.com/zorinto/chinwag): read and reply to WhatsApp from the Mac terminal, through the official WhatsApp Desktop app.

```sh
brew install zorinto/chinwag/chinwag
```

The formula builds chinwag from source with the Swift toolchain from the Command Line Tools; no prebuilt binary is involved.
